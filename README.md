# BCTDS_data

This repository contains the source code, data, and manuscript materials for the project on Broadband Cryogenic Transient Dielectric Spectroscopy (BCTDS). 

## Reproducing Figures

Figures 1–13 are sorted in their respective folders.  
Each folder contains a **single Python script** that is designed to be *click-and-run*.  
Running the script will regenerate the corresponding figure as a PDF/PNG in the same local folder.
